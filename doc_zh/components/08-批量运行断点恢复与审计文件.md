## 计划-执行分离的批处理

`run_osworld.py:50` 的 `build_plan` 是**纯函数**：把"跑哪些任务、每个任务哪些阶段、产物写哪"展开成 JSON 计划，不产生副作用——`--dry-run` 因此可以零成本预览（`run_osworld.py:275` 的 `main`）。`execute`（`:163`）才真正动手：先做全部前置校验（所有写入路径已存在即整体拒绝——**历史输出永不覆盖**；`tools/prepare_osworld_v2_release.py --verify-only` 验证资产完整性），全部通过才建目录、写 `plan.json`、启动模型/VM。

执行以任务为谱系单位：线程池并发（`--concurrency`，默认 1），每个任务是独立子进程 + 独立目录；每步命令独立日志（`<n>.log`）、独立缓存目录（`RSIAGENT_OSWORLD_CACHE_DIR`）；**单任务某阶段失败立即停止其后续阶段，其他任务继续**（`run_osworld.py:249` 的 break 与每任务 `status.json`）。批级退出码只反映"是否有失败任务"，不隐藏任何结果。

ALE 侧同构：`run_ale.py` 的 plan→validate_readiness→run 链路，输出目录强制新建。

## 断点恢复：只认闭合边界

恢复哲学是 **fail closed**：绝不靠猜续跑。

- Phase 1 波次：`resume_completed_boundary=True` 走 `explore/phase1_boundary_recovery.py` 的 `validate_boundary`/`archive_pending`——只接受"完全闭合"的边界，恢复项目/波次计数、Curriculum 历史与上一波结果；任何打开中的 episode 先归档（`explore/phase1_wave.py:792`）。
- 练习内环：`explore/practice_loop.py:1079` 的 `_resume_completed_phase1_boundary` 要求 `state.json` 真实存在、`status == "infra"`、计数自洽（`last_project == projects`），并把持久记忆、已完成结果记录、最后一份无损 Curriculum 轨迹当作"恢复证人"；Agent 工作从不被重建或重评分。
- 分支级：物理故障允许一次从不可变夹具的干净重启（`explore/phase1_wave.py:604`），写重试回执、不提升记忆。
- 传输暂停：可恢复的供应商停机在 `core/loop.py:518` 的 `_call_with_transport_pause` 中原样重试、把暂停从工作时钟扣除——上下文不重置、不伪造助手消息。

## 审计文件与学习环的隔离

根 README 明确：`results/` 下的审计文件留在宿主机，**永不进入 Agent 提示词或记忆**。这一原则有多处机械保障：

- 指令语料（8-gram shingle）仅宿主侧存在（`explore/commit.py:265`），且带来源证明校验（`:279` 的 manifest + SHA-256）；
- 记忆静默审计把与任务指令共享 shingle 的文件拒之门外，拒绝记录只写宿主 JSONL（`explore/commit.py:318`）；
- 考试围栏 `tools/exam_fence.py` 的 `audit_text`/`audit_transcripts` 对提示词与轨迹做目标边界审计（`explore/practice_loop.py` 的 `PracticeHooks` 挂接）；
- 每步批处理命令的 `plan.json`/`status.json`/`outcome.json`/`journal.jsonl` 构成完整证据链，供事后重放，而它们的任何字节都不进学习环。

## 一次批运行的审计面清单

`results/batches/<name>/`：`plan.json`（计划）、`<task>/protocol.json`（协议）、`<task>/<n>.log`（逐步日志）、`<task>/status.json`（步骤链）；RSI 谱系另有 `results/recursive_improvement/<run_name>/` 下的 memory/、memory_journal/、episodes/、waves/、state.json（`explore/phase1_wave.py:735` 的目录布局）。这些文件共同回答：跑了什么、什么证据、记忆如何变化、为什么停止——而 Agent 一个字节也看不到。
